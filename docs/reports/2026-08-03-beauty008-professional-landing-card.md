# Beauty008 — Professional manicure landing card

## Task

Create a premium professional manicure profile opened from Beauty invitation links, using the saved Beauty artwork and the existing booking flow.

## Files inspected

- `src/services/ServiceActivityCard.tsx`
- `src/services/service-activity-card.css`
- `src/services/serviceArtwork.ts`
- `src/services/servicesProfessionalDirectory.ts`
- `src/services/ServicesClientViews.tsx`
- `src/main.tsx`

## Findings

- PR #607 already opens the exact professional card from a `beauty-<slug>` invitation link.
- The existing details view is a generic sheet with one selected service, metadata, one portfolio image, and a booking button.
- Public data currently includes the firm name, service list, prices, durations, location, and public link.
- No public Beauty review or rating source exists, so fabricated reviews or scores must not be shown.

## Changes made

- Added a dedicated Beauty professional profile portal that intercepts the existing professional-card opener, including clicks generated by PR #607.
- Reused the saved manicure sheet and portfolio artwork.
- Added premium hero, service/price list, durations, location, about, booking benefits, portfolio, rating state, reviews state, and sticky actions.
- Added localized RU, UK, CS, and EN copy.
- Reused the existing price-list and booking dialogs rather than duplicating booking logic.
- Added an honest `new profile / no reviews published` state until a real review backend exists.
- Added a pure profile-summary model and regression tests for grouping, deduplication, and price/duration ranges.
