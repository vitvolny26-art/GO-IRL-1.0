# Book V — Product Requirements Scope Split

## Current production truth

- Core Activity create/view/edit/share/join behavior.
- Trusted Telegram auth production path.
- Browser Demo Mode with local-only writes.
- Sport and Generic rendering.
- Activity Chat and weather where enabled.
- Profile basics and provider preferences.
- Map provider choice.
- Google, Apple, and Outlook calendar actions.
- Server-authoritative reminders and provider-neutral notification outbox where verified.
- Telegram and Messenger delivery where current production evidence confirms enablement.

## Proven Closed-Beta baseline

Olomouc and:

1. Volleyball
2. Running
3. Walking
4. Coffee meetup
5. Board games
6. Language exchange

## Approved next phase

Release Preparation and focused post-beta stabilization:

- keep quality gates current;
- verify real Telegram and production behavior;
- preserve release operations;
- improve the proven loop without uncontrolled expansion;
- enable providers only after their individual gates pass.

## Gated

- WhatsApp lifecycle/reminders pending required template, credential, and live-message evidence.
- Instagram Direct pending current app-scoped credentials, publication/access, and complete live lifecycle evidence.
- Broad public launch pending an explicit owner decision and release evidence.

## Long-term vision

AI event discovery, recommendations, RLI/reputation, universal Event Roles, paid marketplace, ticketing, clubs, high-risk social verticals, and broad multi-city discovery.

## Rule

Implementation foundation, schema, adapter code, or an open PR is not equivalent to a shipped public product.
