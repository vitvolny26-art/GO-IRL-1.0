# GO IRL Market Positioning

## Current lifecycle

Closed Beta completed on 2026-07-20. Current phase: Release Preparation and focused post-beta stabilization. Broad public launch is not claimed.

## Core thesis

**GO IRL is a Telegram-first local meetup layer for small real-life activities.**

Mission: **Less scrolling. More life.**

The product converts intent into attendance:

```text
create -> share in Telegram -> join -> coordinate -> meet
```

## Positioning

GO IRL is:

- a structured layer above informal chats;
- a lightweight tool for local micro-meetups;
- an Olomouc-first participation product;
- a trust and coordination layer.

GO IRL is not:

- an event calendar or ticketing platform;
- a sport-only app;
- a dating product;
- a social feed;
- a club CRM;
- an AI recommendation product before validated need.

## Proven baseline

1. Volleyball
2. Running
3. Walking
4. Coffee meetup
5. Board games
6. Language exchange

This remains the default Olomouc release baseline. Expansion requires explicit review and must not dilute event density, release stability, or the attendance loop.

## Release-preparation focus

Clear cards, fast creation, Telegram share, reliable join state, capacity, Activity Chat, organizer trust, profile/provider preferences, and verified operations.

## Guardrail

> Does this make it easier for people to leave the chat and meet in real life?

If not, it is future scope or should be rejected.
